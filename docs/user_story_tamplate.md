## Пример заполнения

# Получение рецептов из имеющихся продуктов

## User Story

Как пользователь, я хочу получать рецепты на основе продуктов, которые есть у меня дома, чтобы готовить без лишних покупок.

## Критерии приёмки

1. Пользователь может отметить продукты как «есть дома».
2. Система показывает рецепты, для которых все ингредиенты отмечены как имеющиеся.
3. Если подходящих рецептов нет, система показывает сообщение и предлагает рецепты с минимальным количеством недостающих ингредиентов.
