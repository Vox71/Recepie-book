## Было / стало

Было:

```text
def handle_starttag(...):
    if tag == "h1" and "name" in props:
        self._in_name += 1
        self._buffer = []
    elif ...
```

Стало:

```text
def handle_starttag(...):
    if tag == "h1" and "name" in props:
        self._start_name()
    elif ...
```

Почему так: длинный метод с 24 проверками тяжело читать, а порядок проверок легко потерять.

Что стало лучше: каждый тег обрабатывается отдельным методом, `handle_starttag` стал коротким
диспетчером.

Сколько это стоило бы чинить потом: было 3 ч, стало 1 ч.
