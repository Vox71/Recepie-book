## Что делаю

Практика 5, вариант V7.

Разложил `parse_ingredients` на три helper-функции и короткий диспетчер. Добавил
`_is_missing_value` для `None`/`NaN`, `_parse_ingredients_text` для строки и
`_pairs_from_container` для словаря/списка. Старые ветки `isinstance` убрал.

## Какие файлы трогал

- `backend/app/importer/povarenok.py`

Область ревью: примерно 100 строк.

## Было / стало

Было:

```text
def parse_ingredients(raw):
    if raw is None: ...
    if isinstance(raw, float) and math.isnan(raw): ...
    if isinstance(raw, str): ...
    if isinstance(raw, Mapping): ...
    elif isinstance(raw, (list, tuple)): ...
```

Стало:

```text
def parse_ingredients(raw):
    if _is_missing_value(raw): ...
    if isinstance(raw, str):
        return _parse_ingredients_text(raw)
    pairs = _pairs_from_container(raw)
    ...
```

Почему так: разбор строки, контейнера и пустого значения — разные обязанности, их проще
тестировать отдельно.

Что стало лучше: главная функция читается сверху вниз, у каждого формата есть своя функция.

Сколько это стоило бы чинить потом: было 2 ч, стало 0,5 ч.
