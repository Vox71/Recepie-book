ПРАКТИКА 5. ОТЧЁТ ПО PR И CODE REVIEW
=====================================

ИНСТРУКЦИЯ
- Замените все поля в квадратных скобках.
- Тексты PR и комментариев копируйте дословно, без пересказа.
- Если комментарий был на английском, оставьте оригинал и добавьте перевод.
- Не удаляйте разделы: если раунд не проводился, напишите «не проводился» и причину.

ОБЩИЕ ДАННЫЕ
-------------
PR: #[номер]
Автор: [ФИО]
Вариант: V[номер]
Ветка: refactor/pract5-[имя]
Base commit: [sha]
Head commit: [sha]
Основной ревьюер: [ФИО]
Арбитр: [ФИО или «не привлекался»]
Дата открытия PR: [дата]
Ссылка на PR: [URL]

ЗАГОЛОВОК PR
------------
[дословный заголовок]

ТЕКСТ PR
--------
[дословное описание PR]

ОБЛАСТЬ РЕВЬЮ
-------------
Файлы и строки:
  [файл:строки]
  [файл:строки]

Примерный размер области: [N] строк

git diff --stat:
  [вывод команды]

PRACT5: БЫЛО → СТАЛО
--------------------
Было:
  [код, сигнатура или описание проблемы]

Стало:
  [код, сигнатура или описание решения]

Почему:
  [причина изменения, принцип, пункт style guide]

Выгода:
  [что стало проще, быстрее или надёжнее]

Техдолг:
  Было: [N] ч / [оценка риска]
  Стало: [N] ч / [оценка риска]
  Обоснование: [почему такая оценка]

Что не менялось:
  - адреса API и HTTP-коды;
  - названия полей JSON;
  - таблицы и колонки базы;
  - поведение для тех же входных данных.
